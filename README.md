## 📌 Project Overview

The **AI Prompt Chatbot** is a modern, high-speed, and interactive web-based conversational AI application built using **Python** and **Streamlit**. It allows users to give **any prompt, question, code task, or complex instruction** and receives accurate, real-time responses generated by state-of-the-art Large Language Models.

The system is powered by high-speed **Groq Cloud** API (`openai/gpt-oss-120b`, `qwen/qwen3.8-27b`) and standard **OpenAI** API with dynamic persona selection, customizable system prompts, and interactive parameter tuning (Temperature, Top-P, Max Tokens).

---

## 🎯 Features

1. **💬 Interactive Conversational AI**:
   - Send any prompt or query and get instant, accurate, streaming answers.
   - Multi-turn conversation memory retaining contextual awareness.

2. **🎭 System Personas & Custom Instructions**:
   - **General AI Assistant**: Helpful, accurate, and multi-domain answers.
   - **Prompt Engineering Mentor**: Evaluates and structures prompt engineering techniques.
   - **Python & CS Tutor**: Code snippets, debugging, and computational logic.
   - **Creative Content Writer**: Imaginative storytelling and creative writing.
   - **Strict Problem Solver**: Concise, direct, and factual answers.
   - **Custom Persona**: Define your own system instructions on the fly.

3. **⚙️ Hyperparameter Controls**:
   - **Temperature Slider ($0.0 - 1.5$)**: Tune between deterministic precision ($0.2$) and creative exploration ($0.9$).
   - **Top-P Slider ($0.1 - 1.0$)**: Control nucleus sampling token thresholds.
   - **Max Tokens Slider ($100 - 2048$)**: Manage response length.

4. **🚀 Dual Cloud Provider Support**:
   - **Groq Cloud**: Lightning-fast inference with `openai/gpt-oss-120b`, `openai/gpt-oss-20b`, and `qwen/qwen3.8-27b`.
   - **OpenAI**: Compatible with `gpt-4o-mini`, `gpt-4o`, `gpt-3.5-turbo`.

5. **💡 Quick-Prompt Launchers**:
   - One-click prompt launchers for Prompt Engineering principles, Python programs, Healthcare AI, and Parameter theory.

## 🚀 Installation & Setup

### 1. Install Dependencies
```bash
pip install -r requirements.txt
```

### 2. Configure API Key
Create a `.env` file or set your environment variable:

```ini
# Groq or OpenAI API Key
OPENAI_API_KEY=your_api_key_here
```

### 3. Run the Chatbot
```bash
streamlit run app.py
```

Open your browser at: **`http://localhost:8501`**
